# Geplante Funktionen

Die folgenden Funktionen werden schrittweise entwickelt. Sie sind noch nicht implementiert.

1. **Produkte anzeigen:** Die App zeigt eine kleine, feste Auswahl an Produkten mit Produktnummern und Preisen an.
2. **Produkt auswählen:** Der Benutzer wählt ein Produkt über seine Nummer aus.
3. **Menge eingeben:** Der Benutzer gibt eine positive, ganzzahlige Menge für das ausgewählte Produkt ein.
4. **Preis berechnen:** Die App multipliziert den Produktpreis mit der Menge und addiert das Ergebnis zur Gesamtsumme.
5. **Einkauf fortsetzen oder beenden:** Der Benutzer kann weitere Produkte auswählen oder den Einkauf beenden.
6. **Gesamtsumme anzeigen:** Beim Beenden des Einkaufs zeigt die App den Gesamtpreis an.
7. **Ungültige Eingaben behandeln:** Ungültige Produktnummern und Mengen werden mit verständlichen Meldungen abgelehnt. Der Benutzer kann seine Eingabe anschließend wiederholen.
