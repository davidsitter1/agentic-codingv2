# Einkaufsapp – einfacher Java-Konsolenshop

**Autor:** davidsitter1

## Projektbeschreibung

Dieses Projekt entsteht im Rahmen einer Lehrveranstaltung an der Universität mit Unterstützung durch agentic coding. Die Einkaufsapp wird als einfache Konsolenanwendung in Java entwickelt.

Benutzer können feste Produkte mit Preisen ansehen, ein Produkt auswählen und eine Menge eingeben. Die App berechnet den Preis für die gewählte Menge und addiert ihn zur Gesamtsumme. Anschließend können weitere Produkte ausgewählt oder der Einkauf beendet werden.

## Lernziel

Das Projekt soll so einfach wie möglich bleiben, damit Einsteiger den Code lesen und verstehen können. Geübt werden strukturierte Programmierung, Eingaben mit `Scanner`, einfache Klassen oder Records, Bedingungen mit `if`, arithmetische Operationen und Schleifen.

Vererbung, abstrakte Klassen, Interfaces, Collections, Streams, Frameworks und andere höhere Java-Sprachmittel werden nicht verwendet. Änderungen am Code werden auf Deutsch erklärt, einschließlich ihrer Aufgabe, der verwendeten Sprachkonzepte und eines kurzen Beispiels.

## Geplanter Umfang

Die erste Version verwendet wenige feste Produkte. Datenbank, Anmeldung, grafische Oberfläche und Speicherung sind nicht vorgesehen.

Das Projekt enthält derzeit die Dokumentation. Der Java-Code wird in späteren Aufgaben entwickelt.
